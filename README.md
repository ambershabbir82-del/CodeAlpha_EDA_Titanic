# Titanic-EDA-Analysis
Exploratory Data Analysis on the Titanic dataset — exploring survival patterns, passenger demographics, and key trends using Python (Pandas, Matplotlib, Seaborn).

## What's Inside
- Data cleaning (handling missing values)
- Statistical summary of passengers
- Visualizations: survival rate by gender, class, age
- Key insights and findings

## Tools Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook
